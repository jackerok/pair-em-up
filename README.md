# Pair-em-up

- Соседние клетки: Числа в вертикально или горизонтально соседних клетках всегда можно соединить (сопоставить).
- Одна строка/один столбец: Числа в одной строке или одном столбце можно соединить, если клетки между ними пустые.
- Границы строк: Последнее число одной строки можно соединить с первым числом следующей строки.

## Игровая механика

- Удаление клеток: Когда корректная пара успешно сопоставлена, обе клетки становятся пустыми, и числа навсегда удаляются с сетки.

- Некорректные пары: При попытке сопоставить неверную пару игрок получает визуальную/звуковую обратную связь, но числа остаются на месте.

- Управление сеткой: По мере очистки клеток оставшиеся числа сохраняют свои позиции (никакого автоматического смещения не происходит).

## Начальный экран

- Название игры: «Pair 'em Up», отображённое крупно и заметно.

- Автор: Имя пользователя GitHub автора с кликабельной ссылкой на его профиль.

- Выбор режима: Кнопки или интерфейс для выбора между режимами Classic, Random и Chaotic.

- Кнопка продолжения игры: Появляется и становится активной только тогда, когда существует сохранённая игра; позволяет продолжить ранее начатую.

- Доступ к настройкам: Панель или модальное окно настроек с управлением звуком и темой.

- Доступ к результатам: Панель или модальное окно с таблицей результатов.
